## Workflow

1. `src/content/site/profile.md`에서 소개를 수정합니다.
2. `src/content/projects/*.md`에서 프로젝트 설명과 repo 연결 정보를 관리합니다.
3. `pnpm sync:github`를 실행해 GitHub 저장소 메타데이터와 최근 커밋을 다시 가져옵니다.
4. `pnpm dev` 또는 `pnpm build`로 결과를 확인합니다.
