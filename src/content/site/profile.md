## About

안녕하세요. 저는 AI를 활용해 낯선 도메인의 문제를 빠르게 구조화하고, 백엔드·프론트엔드·인프라를 연결해 실제 운영 가능한 결과로 만드는 엔지니어입니다.

현재는 하이닉스 AMHS 모니터링 시스템 관련 업무를 수행하며 반도체 팹 자동화 도메인을 빠르게 익히는 동시에, agent tool, LangGraph, Spring, 프론트엔드, CI/CD, 인프라 전반에서 Claude를 활용해 결과를 만들어내는 방식을 실전에서 다듬고 있습니다.

저는 단순히 기능을 추가하는 것보다, 도메인 개념이 어떻게 API, 화면, 운영 흐름으로 이어지는지 일관되게 설계하는 일을 중요하게 생각합니다. 복잡한 문제를 다루더라도 아키텍처를 불필요하게 무겁게 만들지 않고, 팀이 계속 가져갈 수 있는 구조와 코드로 정리하려고 합니다.

## Collaboration

함께 일할 때는 답만 빠르게 내는 것보다, 왜 그렇게 판단했는지와 어떤 구조로 구현했는지가 남는 협업을 지향합니다.

그래서 최근에는 작업을 **상황 → 판단 → 구현 → 결과** 형식으로 정리하려고 합니다. 문제의 맥락, 선택 이유, 실제 구현, 얻은 결과를 짧게 남겨두면 팀 신뢰와 재사용성이 함께 올라가기 때문입니다.

저는 프론트엔드, 백엔드, 인프라 중 한 영역에만 머무르기보다 제품 전체 흐름에서 병목이 생기는 지점을 찾아 연결하는 역할을 맡는 편입니다. 필요한 기술은 빠르게 학습하되, 최종 결과는 팀이 계속 가져갈 수 있는 형태로 정리하려고 합니다.
